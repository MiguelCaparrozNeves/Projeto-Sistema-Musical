# 🎵 Sistema Musical Web

Projeto de um sistema musical interativo desenvolvido para gerenciamento de artistas, músicas e bibliotecas musicais através de uma interface web responsiva e moderna.

## 🚀 Tecnologias Utilizadas

- **HTML5:** Estruturação semântica de todas as páginas e formulários.
- **CSS3:** Estilização global com variáveis CSS (`:root`), Flexbox, CSS Grid e media queries para responsividade.

---

## 📁 Estrutura de Arquivos

- `index.html`: Menu principal e painel de navegação do sistema.
- `login.html`: Tela de autenticação com formulário de login e credenciais de teste.
- `cadastro_artista.html`: Formulário de cadastro de artistas e tabela de exibição do elenco.
- `cadastro_musica.html`: Formulário de cadastro de faixas com suporte a links do YouTube, capas e letras.
- `listagem_musicas.html`: Biblioteca musical com sistema de busca e filtros gerais.
- `styles.css`: Folha de estilos centralizada para todas as páginas.
